# FkstClient v1.10.0（测试版）

第三方「疯狂刷题」客户端，基于官方 APK 逆向分析实现。本版本主要改了两块体验。

## 更新内容

### 1. 消息通知改版（之前只显示标题，看不出发生了什么）
- 不再干巴巴显示一条标题，而是按**动作类型**还原成完整语义：
  - `拾秋 评论了你的笔记` + 评论原文 + 《相关文章标题》
  - `小明 赞了你的笔记` / `赞了你的评论`
  - `小红 给你投币了`
  - 系统消息（如「老师的解析被认可」「被移出群组」）走中性样式
- 每条通知显示**评论/回复原文**和**相关文章标题**；点整张卡片直接跳到那篇文章的详情页（系统消息没有关联文章，不跳）。
- 顶部增加分类筛选：**全部 / 评论 / 点赞 / 投币 / 系统**。

### 2. 评论区支持发图
- 评论输入框新增「图片」按钮，可选一张本地图；
- 选图后先传到笔记图库（与发布笔记同款目录），再把图片地址（`content_url`）随评论一起提交；
- 评论与回复里的配图在列表里正常展示，点击可全屏查看 / 保存。

## 已知限制（诚实说明）
- 评论发图依赖 `SetSTNoteComment1` 的 `content_url` 字段（字段名从官方端 `WorkCommentFragment` 与笔记评论返回结构里确认）。受限于测试账号被服务端限制发言（发评论恒回 `res=1`），这条链路**未做端到端真机验证**；UI 侧已确保「能选图、能上传、能随评论提交」三步走通，真机可用账号上应可直接发出带图评论。
- 若服务端对评论图片做了额外审核或字段口径不同，可能图片不显示——届时需要再抓一次包校准。

## 安装
下载下方 APK 直接安装（Android 7+）。首次打开会要求同意用户政策，并说明本客户端不做官方在线答题（服务端门禁挡着，恒回「非法访问」），改用「试卷库」浏览真实试卷并直接看题目/答案/解析。
