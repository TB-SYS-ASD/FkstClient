# FkstClient v1.11.0（测试版）

第三方「疯狂刷题」客户端。本版本把 `fkst-desktop-main` 的刷题逻辑接了进来，
终于补上之前一直做不了的「真·在线答题 / 交卷」。

## 更新内容

### 1. H5 实时练习（核心：真能刷题了）
- 试卷详情页右上角新增 ▶「实时练习」按钮。
- 点它会用**本账号的合法会话**拼出官方 `paperExercises-v18` 页面 URL
  （HMAC-SHA256 签名，逻辑来自 desktop 的 `letter.py::build_paper_exercise_url`，
  CEO 破解 + 实测验证），丢进内置 WebView。
- 因为走的是官方 H5 + 合法会话，**能正常答题、交卷**——绕开了第三方 native
  交卷接口恒回「非法访问」的死结。会话身份全在带签名的 query 参数里，不需要同步 cookie。
- ⚠️ 登录态是前提：`loginToken` / `tokenSeed` 现在会随登录一并保存（之前 `login()`
  漏抓了这两个，导致 H5 签名种子取不到、只能看题）。没登录时点按钮会提示先登录，
  登录状态在重启后也能保留（会话持久化补了这两个字段）。

### 2. 我的答题记录
- 「我的」页新增「答题记录」入口（GetRecordShuatiQuestion1，native 接口）。
- 逐条回看做过的题：上一题 / 下一题 翻页，滚到最后一题自动续拉（记录 over 恒 False，靠短页停）。
- 只显示题干 + 选项（服务端记录里没有对错）；想看正确解析可配合试卷库里的题目。

## 已知限制（诚实说明）
- H5 实时练习是官方网页，体验取决于官方 H5 本身（样式、广告、个别机型 WebView 兼容性），
  客户端只负责把它正确加载出来。
- 答题记录接口只读题干+选项，不含对错，所以记录页不显示「答对/答错」。
- 评论发图（v1.10.0）仍在测试账号上未做端到端真机验证，本版未改。

## 安装
下载下方 APK 直接安装（Android 7+），覆盖旧版即可（签名一致）。
首次打开若要求同意用户政策、看完「为什么没有刷题模块」说明，那是为了讲清
第三方客户端的边界——现在那页也更新了：1.11.0 起已经能真刷题了。
