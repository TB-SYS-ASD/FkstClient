# FkstClient V1.7.0

> 第三方「疯狂刷题」客户端 · 版本 1.7.0（versionCode 8）

## 新增

### 📜 首次启动引导（只出现一次）

第一次打开 App 时会依次看到两页，之后无论登录、重启都不会再出现：

1. **用户政策** —— 非官方第三方客户端的使用须知与隐私说明
   （登录凭据只存本机、不收集不分享数据、清数据即登出），
   勾选「我已阅读并同意」才能继续；不同意只能退出。
2. **为什么没有「刷题」模块** —— 既然叫「疯狂刷题」，这个客户端却不带刷题，
   先给用户一个交代：
   - **题目和知识点对不上**：官方题库接口不接受任何筛选参数，
     选「小学·数学·图形与几何」和选「高中·英语·完形填空」，服务端返回的是同一批题。
     界面上能选、题却不跟着变，这种「看起来能用」的功能比没有更糟。
   - **试卷点不进去**：试卷列表拉得到，但每张卷子的题量字段恒为 0，
     取题接口恒返回空，网页版答题页也有访问限制。
   - 刷题界面其实完整做出来过一版，实测发现以上两条都是服务端限制、客户端绕不过去，
     所以整块拿掉，客户端专注社区功能（发现 / 搜索 / 私信 / 发布笔记 / 收藏 / 投币）。
   - 哪天官方把「按知识点出题」开放了，刷题模块随时可以加回来。

> 「清除应用数据」后政策页会再弹一次，这是预期行为。

### 🔄 更新检查（从 GitHub）

- **启动时静默检查**一次 GitHub Releases（`releases/latest`），
  有新版本才弹窗，失败 / 超时 / 没有新版完全无感，绝不打扰。
- 弹窗三选一：**去下载**（优先用 Release 附带的 apk 资产直链，没有就打开发布页）、
  **跳过此版本**（记住这个 tag，不再提示；下个版本照常提示）、**稍后**（本次不弹）。
- 设置页「关于」里加了**手动检查**按钮，并显示当前版本号（不再写死在代码里）。

> 注意：GitHub 上的 Release 需要用规范的版本 tag（如 `v1.7.0`），
> 客户端才能识别并弹窗；tag 解析不出 `v?x.y.z` 时会静默跳过，不会误报。

## 技术细节

- 新增 `ui/screens/OnboardingScreen.kt`（两步引导）、`core/UpdateChecker.kt`
  （GitHub Releases 版本检查与比较）。
- `Repository` 增加持久化标记：`policy_agreed` / `no_exercise_explained` /
  `skipped_update_tag`。
- `AppNav` 启动路由增加引导门禁；版本比较逻辑已用 JVM 侧对照测试验证
  （`v1.7.0 > 1.6.0` ✓、`v1.10.0 > v1.9.0` ✓、预发布后缀和乱串一律不提示 ✓）。
- 打开了 `buildConfig`，版本号统一从 `BuildConfig.VERSION_NAME` 取，
  设置页「应用版本」随之修复（此前显示的还是 1.5.0）。
